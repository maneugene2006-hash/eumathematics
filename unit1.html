Unit 1: Sets

Definition

A set is a group of objects with certain similar characteristics.

A = {1,2,3,4,5}

Examples

  • Natural numbers
  • Even numbers
  • Prime numbers

Exercise

Write the set of letters in the word RWANDA.

Subset

A subset is a small part of a universal set.

Example

If we have the universal set:
A = {1,2,3,4,5}

  • K = {1,2} is a subset of A

Empty Set

An empty set is a set that has no element.

Example

If we have the universal set:
A = {1,2,3,4,5}

  • K = { } is an empty set
